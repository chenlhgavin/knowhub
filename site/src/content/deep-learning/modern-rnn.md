> 从"记不住长期依赖"的病根，到 GRU / LSTM 的门控解药，再给记忆加深、加方向。

上一篇的结账单很冷酷：**梯度消失无解，除非换结构**。普通 RNN 里，梯度每往回退一步都要被同一个权重矩阵再乘一次——隔 40 个词的关联，梯度传回去早已归零，裁剪和截断都救不了。

这一篇就是"换结构"本身。药方出奇地一致：**给记忆装阀门**——让模型自己学会"该记的记牢、该忘的忘掉、该跳的跳过"，从结构上修一条梯度不衰减的直通路。

这是 RNN 系列的第 4 篇（完结篇）。读完你会得到：

1. "门"凭什么能治梯度消失——一条 0~1 阀门守护的直通路；
2. GRU 两个门、LSTM 三个门加一条传送带的分工与取舍；
3. 深度、双向两个正交增强，以及双向"只能当编码器"的边界。

## 一、病根与总方案：给记忆装一个 0~1 的阀门

> 本节回答：门控凭什么能治梯度消失？

普通 RNN 有三个痛点，GRU 和 LSTM 都是冲着它们来的：

- **梯度消失**——长距离依赖学不动（主症，上一篇算过账）；
- **不是每步都同等重要**——开头的关键词可能要记很久，普通 RNN 没法重点保留；
- **有些词就是噪声**——希望能跳过，而不是一视同仁揉进记忆。

核心诉求一句话：**让模型自己学会"该记的记牢、该忘的忘掉、该跳的跳过"。** 办法就是加"门"。门本质是一个 sigmoid 层（把任意数压到 0~1 之间的激活函数），输出的每个元素代表一道阀门开多大——0 关死，1 全开。

![门控为什么能治梯度消失：把连乘的乘数从定死的 W×tanh′ 换成可学到 1 的门](/knowhub/images/articles/modern-rnn/blog-mrnn-gating.png)

图的左半是病根：普通 RNN 里，梯度每往回传一步，都要乘上一对由结构定死的乘数——W 和 tanh 的斜率，普遍小于 1。50 步的序列，第 1 步的梯度要背 49 个乘数，约缩到 0.00002——长依赖学不动。

右半是药方：门控改写了更新公式——**新记忆 = 门 × 旧记忆 + (1−门) × 新内容**。旧记忆这一项**不过 W、不过 tanh**，是一条加法旁路；梯度沿旁路往回传，每步只乘门值。

> **一句话记住本文：连乘躲不掉，但乘数换了——从定死的 W×tanh′，换成可学到 1 的门。** 门学到接近 1，乘 1 不衰减，重要信息和梯度都能沿这条直通路滑到很远。

**本节结论：GRU 和 LSTM 的共同底层，是用可学习的 0~1 阀门给记忆和梯度修直通路——区别只在这条路怎么修。**

## 二、GRU：两个门，一条信息高速公路

> 本节回答：最精简的门控单元，怎么用两个门管住记忆？

门控循环单元（GRU，Gated Recurrent Unit）只用两个门：**重置门 R** 和**更新门 Z**。它们长得一模一样——都是把"当前输入 + 上一刻记忆"各乘一套权重、相加后过 sigmoid，只是权重独立、学到不同本事（公式见下图）。

**第一步，重置门过滤旧记忆、起草候选。** 先起草一份候选新记忆：普通 RNN 是直接拿"当前输入 + 旧记忆"过 tanh；GRU 的不同点，是在用旧记忆之前先让重置门把它按元素卡一道（记忆的每个维度各自乘上 0~1 的开度）。

R 接近 0 就关掉旧记忆，草稿几乎只看当前输入——遗忘过去、重新开始；R 接近 1 就退化回普通 RNN。所以**重置门管短期依赖**：决定这一步要不要跟过去一刀两断。

**第二步，更新门在旧、新之间插值。** 有了旧记忆和候选草稿，用哪个？更新门做加权平均：新记忆 = Z × 旧记忆 + (1−Z) × 候选——正是第一节那条"加法旁路"的 GRU 版本。

Z 接近 1 就几乎原样保留旧记忆，这一步**跳过**，记忆和梯度都直通到下一步；Z 接近 0 就完全采纳新草稿。所以**更新门管长期依赖**：只要它连续很多步接近 1，开头的信息就能无损传到末尾。

![GRU：两个门，重置管短期、更新管长期](/knowhub/images/articles/modern-rnn/blog-mrnn-gru.png)

把"Z 接近 1 连续好几步"连起来，就是一条**信息高速公路**：遇到噪声词不写入（Z≈1），遇到关键词才写入（Z≈0）——"关键词记很久"和"跳过噪声"是同一个动作的两面。

> 一句话记牢分工：**重置门**是"草稿要不要参考旧笔记"（短期，起草**前**干活）；**更新门**是"正式笔记要不要换成新草稿"（长期，起草**后**干活）。注意两者方向相反：重置门≈0 是忽略旧记忆、保留当前输入；更新门≈1 是忽略当前输入、保留旧记忆。

**本节结论：GRU 用重置门制造局部断点、用更新门架时间直通桥——两个门，把"记、忘、跳"全管了。**

## 三、LSTM：三个门 + 一条记忆传送带

> 本节回答：比 GRU 更早、更复杂的 LSTM，凭什么成了经典？

长短期记忆网络（LSTM，Long Short-Term Memory）比 GRU 更早出现（1997 年），目标一样，思路更精巧：**把"记忆"和"输出"拆成两条线**——

| | 记忆元 C（cell state） | 隐状态 H（hidden state） |
|---|---|---|
| 角色 | 内部长期记忆**传送带** | **对外输出**的窗口 |
| 流向 | 只在内部一步步传给下一刻 | 送进输出层做预测 |

> 比喻：C 是工厂里一直转的传送带，信息平稳流动；H 是从传送带上取下来展示的那份样品。

控制传送带的是三个门（都是 sigmoid）：**遗忘门 F** 管旧记忆保留多少，**输入门 I** 管新信息写入多少，**输出门 O** 管记忆放出多少。

每一步三件事：先起草候选记忆（和普通 RNN 的 tanh 更新一模一样），然后"新传送带 = F × 旧传送带 + I × 候选草稿"，最后输出 H = O × tanh(新传送带)（公式见下图）。

![LSTM：三个门 + 一条独立的记忆元 C 传送带](/knowhub/images/articles/modern-rnn/blog-mrnn-lstm.png)

三个细节看懂精髓：

**草稿相同，地位不同。** 普通 RNN 里 tanh 的结果就是新记忆，每步无条件全量覆盖——相当于把两个门焊死在"全忘旧、全写新"；LSTM 里它只是草稿，写不写由输入门决定，旧记忆另有遗忘门保护。F=1、I=0 时，旧记忆原封不动传下去——信息无损，梯度直通。

**传送带只走加法。** 旧记忆沿 C 传播时，只经历"乘一个门、加一份新内容"，不再反复过 tanh 和权重矩阵——这正是梯度能沿 C 平稳流动、不易消失的原因，也是 GRU 高速公路在 LSTM 里的对应物。

**写入和读出是两个独立开关。** O 接近 0 时这一步几乎什么都不输出，但 C 的写入照常进行——**先记着、以后再用**。比如情感分类中途读到关键否定词，现在还不用预测，就存着不说；到句末再打开输出门。GRU 只有一个 H，想留在记忆里就必然暴露在输出里，这种精细控制做不到。

和 GRU 对照，取舍一目了然：

| | LSTM | GRU |
|---|---|---|
| 门的数量 | 3 个（遗忘/输入/输出） | 2 个（重置/更新） |
| 记忆与输出 | 分开（C + H） | 合一（只有 H） |
| 参数 / 速度 | 更多、更慢 | 更少、更快 |

> 实践经验：两者效果通常**相当**，GRU 更轻快，LSTM 表达更细——先试哪个都行。

**本节结论：LSTM 的精髓是那条只走加法的传送带——记忆有专线，输出有开关，梯度有直通。**

## 四、深度 RNN：横向传记忆，纵向传特征

> 本节回答：一层隐藏层不够抽象，怎么办？

到这里的 RNN/GRU/LSTM 都只有一层隐藏层，非线性和抽象层次有限。深度 RNN 的做法很直接：把隐藏层**纵向叠 L 层**，下层的输出当上层的输入。沿时间展开后是一张二维网格——**横向是时间（向右传记忆），纵向是层（向上传特征）**：

![深度 RNN：横向传记忆、纵向传特征的二维网格](/knowhub/images/articles/modern-rnn/blog-mrnn-deep.png)

每个格子的新状态由两个来源合成：**左方**是本层上一时刻的记忆（这是"循环"部分），**下方**是下层同一时刻的特征（最底层就是原始输入）。输出只取最顶层，每层权重独立。底层像"逐字逐句听"，高层像"把握整段主旨"。

**"深度"和"门控"是两个正交的维度**：横向记得久靠 GRU/LSTM，纵向抽象深靠叠层，每层单元可以原地换成 GRU 或 LSTM。实践中也几乎都这么组合——叠深恰恰会加剧梯度消失，普通 RNN 叠层几乎不可用；常用 2~3 层，很少更多。

**本节结论：深度解决"抽象不够"，门控解决"记不久"——两者正交，所以放心组合。**

## 五、双向 RNN：既看上文，也看下文

> 本节回答：预测某个位置时，能不能连它后面的内容一起看？

单向 RNN 预测某个词时只知道它前面的内容，但很多任务要看后文才判断得了："我 ___ 。"可能填"很好"；"我 ___ 饿了，可以吃半头猪。"就得填"非常"——答案取决于右边。

双向 RNN（Bi-RNN）的做法：**跑两条 RNN，一条从左到右、一条从右到左，在每个位置把两个方向的记忆拼接起来**——每个位置都同时拥有"左边攒的上文 + 右边攒的下文"：

![双向 RNN：正向看上文、反向看下文，拼接成完整上下文](/knowhub/images/articles/modern-rnn/blog-mrnn-bi.png)

典型例子是词性标注："他 用 锁 锁 门"里两个"锁"字长得一样、词性不同。第一个"锁"处，正向链带着"他 用"——介词后多半接名词；反向链带着"锁 门"——后面还有动词顶着。拼起来才判得出名词。训练和其他 RNN 完全同一套：一张计算图、一次反传，两条链的参数同步更新。

但它有一个**致命边界**：反向链要从句尾往前算，必须先拿到完整序列，所以它**不能做语言模型和生成**。

更隐蔽的是训练目标：拿"预测下一个词"训练双向网络，反向链在位置 t 早已读过下一个词，等于**抄答案**——损失轻松归零，但什么都没学到。双向只能配"给定完整序列、标签另给"的任务，或先把目标词挖掉的完形填空（BERT 的思路正源于此）。

| ✅ 适合（有完整序列） | ❌ 不适合（要预测未来） |
|---|---|
| 完形填空、文本分类 | 语言模型（预测下一个词） |
| 命名实体识别、词性标注 | 文本 / 序列生成 |
| 作为**编码器**给整句提特征 | 实时 / 流式预测 |

成本上参数和计算约为单向的 2 倍，但两条链可并行，实际耗时增加不多。

**本节结论：双向 RNN 是强大的"编码器/特征提取器"，不是"预测未来"的工具。**

## 结语

三条 takeaway：

1. **门控治住梯度消失**：把连乘的乘数从定死的 W×tanh′ 换成可学到 1 的门，重要信息和梯度沿直通路滑到很远——GRU 两个门合一条 H，LSTM 三个门加一条只走加法的传送带 C；
2. **GRU 与 LSTM 效果通常相当**：GRU 轻快，LSTM 能"记住但先不说"——先试哪个都行；
3. **门控管记忆、深度管抽象、双向管视野**：三个正交维度，可自由组合成"深度双向 LSTM"。

**边界与局限**：门控延长了记忆，但没有消除"把历史压进固定大小账本"这个瓶颈——序列极长时照样丢信息；双向只能当编码器，生成任务用不了。

**下一步**：有了这些组件，该去解决一个真实任务了——**机器翻译**，输入输出都是变长序列。下一篇《一文读懂 seq2seq》里，GRU/LSTM 会填进"编码器-解码器"骨架，双向 RNN 正好去当编码器。
